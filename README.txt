SUBIR ESTOS ARCHIVOS A LA RAÍZ DE GITHUB PAGES.

Importante:
- YouTube no permite mostrarse dentro de un iframe, por eso la versión anterior no funcionaba.
- Esta versión abre directamente https://m.youtube.com/.
- Primero abrí la URL de GitHub Pages en Brave.
- Una vez que Brave detecte la PWA, instalala desde el menú de Brave.
- Al abrir la aplicación instalada, se abrirá YouTube directamente.
